---
title: "创建 API 密钥"
description: "获取并使用 API 密钥"
---

API 密钥（Token）是访问平台接口时使用的身份凭证，通常以 `sk-` 开头。一个账号可以创建多把密钥，建议按使用环境或项目分别管理，例如开发测试、线上服务、不同应用等，便于后续设置权限、额度、限速或单独停用。

## 1. 进入密钥管理页面

登录平台后，打开控制台中的 **API 密钥** 页面（`/keys`），点击右上角的 **创建 API 密钥**。

![API 密钥管理页面](/images/api-key-list.svg)

## 2. 配置密钥信息

创建页面包含三个部分。

![创建 API 密钥页面](/images/api-key-create.svg)

### 基础信息

**名称**：用于标识这把密钥的用途，例如 `qwen`、`for_dev` 等。

**分组**：决定该密钥可调用的模型范围、使用协议，以及对应的计费倍率。

**数量**：可一次生成多把相同配置的密钥，默认创建 1 把。

**过期时间**：默认长期有效；也可以设置为 1 天、1 个月等指定期限。

### 额度设置

**无限额度**：开启后，该密钥不会设置独立消费上限，实际可用额度仍受账户余额限制。

**额度上限**：可为单把密钥设置单独的可用额度，例如 ¥10、¥100 等。

### 访问限制

**模型限制**：可选择允许该密钥调用的模型，未选中的模型将无法通过该密钥访问。

**IP 白名单**：可限制密钥仅能从指定 IP 或 CIDR 网段使用；留空则不限制来源地址。每行填写一个 IP 或网段。

<Tip>
  不确定该选哪个分组时，可以前往模型广场查看各分组支持的模型及对应倍率。
</Tip>

## 3. 保存密钥

创建完成后，可在令牌列表中点击 **复制** 获取完整密钥。

完整密钥通常只建议在创建后及时保存到安全的位置，例如密码管理器、服务器环境变量或密钥管理服务中。列表中显示的密钥一般会进行脱敏处理。

## 已有密钥的管理

密钥列表会展示每把密钥的当前状态，例如启用、已禁用、已过期或额度耗尽，同时也会显示剩余额度、总额度、所属分组、模型权限和 IP 限制等信息。

你可以随时编辑已有密钥的配置，也可以根据需要禁用或删除不再使用的密钥。
