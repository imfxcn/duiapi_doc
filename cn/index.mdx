DUI API 为开发者提供简洁的 RESTful 接口，你可以通过标准 HTTP 查询资源、触发 UI 工作流，并构建集成。

DUI API 是面向开发者的 REST API。它让你以编程方式访问数据和 UI 驱动的工作流。无论你是在构建内部工具、自动化重复任务，还是把 DUI 集成到现有技术栈中，DUI API 都会提供你快速交付所需的端点、认证方式和文档。
