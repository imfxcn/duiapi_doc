欢迎来到 Duiapi。在这里，你可以学习如何注册账号、充值额度、创建 API 密钥、发起第一次请求，并把 Duiapi 接入常用 Agent 工具和应用。

本文档主要包括三部分：**概述**、**Agent 配置指南** 和 **API 参考**。你可以先从概述开始完成账号和密钥准备，再根据使用场景选择 Claude Code、Codex 或 OpenCode 的配置指南，最后查看 API 参考接入自己的应用。
