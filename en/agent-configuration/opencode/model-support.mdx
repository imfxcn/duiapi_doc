---
title: "Model support"
description: "Models supported by OpenCode"
---

OpenCode currently supports the following model families:

| Model family | Status |
| --- | --- |
| Qwen | Supported |
| GLM | Supported |
| DeepSeek | Supported |

You can configure these model IDs:

- `qwen3.7-max`
- `glm-5.2`
- `deepseek-v4-pro`
