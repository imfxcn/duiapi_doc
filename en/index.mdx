Welcome to Duiapi. Here, you can learn how to create an account, recharge credits, create API keys, send your first request, and connect Duiapi to common agent tools and applications.

This documentation has three main sections: **Overview**, **Agent configuration guide**, and **API reference**. Start with Overview to prepare your account and API key, then choose the Claude Code, Codex, or OpenCode configuration guide based on your workflow. Finally, use the API reference to integrate Duiapi into your own applications.
